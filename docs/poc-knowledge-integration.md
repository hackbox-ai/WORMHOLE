# PoC knowledge access

WORMHOLE retains source packages, library management, retrieval, product aliases, version applicability, candidate associations, task pinned snapshots and delivery records.

Basic version does not contain old internal libraries and full third-party snapshots. Explicitly import the user's own source package through the page or add entries manually. The format entry is`pihost/src/domains/pocs/catalog.ts`.

Separate knowledge content from execution: This module does not automatically execute Python or Nuclei templates. The actual verification still uses the task's original tools, authorization, interception approval and evidence write-back processes.
