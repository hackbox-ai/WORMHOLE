# Accounts and Appearance

## Modify username

Modify the administrator username in the account and enter the current password as prompted to confirm. After saving, log in with the new username and keep the password unchanged. Don't confuse the page display name with your actual login name.

## Change password and exit

Changing the password requires verification of the current password. Exit ends the current browser login. When using a shared computer, check that the browser has saved the test credentials after exiting.

## Appearance and Preferences

The appearance page sets the theme and layout, and the relevant preferences are saved in the current browser. It may be restored to default after changing browsers or clearing site data. Instructions for use support light and dark themes and narrow screen reading.
