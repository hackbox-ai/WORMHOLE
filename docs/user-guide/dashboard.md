# Dashboard

## View overall status

The dashboard summarizes task progress, vulnerability discovery and execution consumption. First select the required time range, model or task caliber, and then interpret the statistics.

## Token usage

The statistical scope of task summary, call-by-call and task and conversation summary are different. Uncached input, cache hits, and outputs are displayed separately; the cache hit rate is calculated according to the corresponding caliber.

When checking the usage, enter the call one after another to confirm the time, configuration and session ownership. When the task does not call the model, the request fails and no usage is returned, or the record has not been written, the token cannot be inferred from the number of tasks.

## View details

Go from a task or discovery to actual details, checking evidence and execution status. Summary graphs are used to locate changes. The specific reasons need to be combined with tasks, traces and logs.
