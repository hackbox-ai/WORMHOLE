# Skill

## New and Import

You can create or upload a skill compressed package on the Skill page. The name uses lowercase letters, numbers, and hyphens and is 1–64 characters long. The text should describe applicable conditions, operating procedures, output requirements and limitations.

## Linked with Agent and MCP

Configure visible Agents so that roles can discover and load Skills. When an MCP is associated, the corresponding tools are disclosed when loading skills. The skill definition method and process, the actual tool invocation is still executed by the Agent.

The missing skills list displays skills that the Agent has named but do not exist in the current library, which can be used to complete methods or correct names. Do not treat roll call records as running successfully.

## Verify

In an isolated task, have the authorized role handle scenarios appropriate for the skill, checking that the session loads the skill, that the tools are available, and that the results are written back. Merely successfully importing files does not prove that the workflow has been completed.
