# Workspace

## View task products

The workspace is used to view task files, command output, and intermediate products. View occupancy and classification by task, preview or download if necessary.

Occupancy statistics are used to determine which tasks need to be organized. The file directory is not equivalent to the vulnerability evidence library. When cleaning, upload attachments, intermediate files and registered evidence need to be distinguished.

## Manual cleanup

After selecting the task and cleanup scope, check the preview and confirmation information. When cleaning ordinary files, the attachments and evidence identified by the system are retained; unregistered files still require manual judgment. It cannot be restored after deletion.

## Archive and delete

Task archiving compresses relevant records and products into cold storage and supports restoration. Workspace cleanup only processes selected file ranges. Task deletion can further affect associated data, and options must be checked by pressing the confirmation box.

When the file cannot be opened, you can download it and use a suitable program to view it. The file should not be judged to be damaged based solely on failed preview.
