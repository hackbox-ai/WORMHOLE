# Evidence and conclusion

## A reviewable test record

Record in detail of record_fact:

- hypothesis: negated security invariant.
- target/identities: Targets and test subjects, with labels and non-sensitive identities only.
- baseline / control / changed_variable: legal baseline, negative control, unique change.
- observed: A true response, object assignment, or command result; separate from expected.
- evidence_refs: real traffic ID, tool call/output reference, workspace file path and hash.
- outcome: supported / rejected / inconclusive / blocked (method label, platform enumeration unchanged).
- coverage: acquisition/tested/untested boundaries; tries, stop reasons, and reopen_when.

Summary In a word, evidence retains the most probative fragment; do not copy all tokens, cookies, passwords and original sensitive text to the summary/report. The complete content is kept by the existing controlled evidence module.

## Exclude false positives

Under the same request protocol, the random non-existent identifier also produces the same difference → enumeration is not supported. Only invalid requests return 400 → authz bypass is not supported. Path variant returns only home page HTML → Controller reach is not supported. config/version/CVE hits → only form candidates, report_finding is not supported.

## Impact boundary

Can access a test object, reports only confirmed object and identity boundaries, does not infer unlimited reads, remote execution, or full-tenant impact. Verification is subject to task constraints, approvals and budget constraints; when it cannot be completed, record "what is missing and what conditions are met to restart", and no unfounded completion time is promised.

HTTP uses traffic_search to locate and then traffic_get to verify; the truncated large text is read by the currently visible tool and is not disguised as a complete forensics. The traffic quoted must correspond to this experiment. When there is no capture, you can retain the real text/command evidence, clarify the evidence limits, and do not re-perform operations with side effects for patching the package.
