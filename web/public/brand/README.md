# WORMHOLE artwork

- `wormhole-logo.jpg`: original artwork supplied by the project owner, unchanged.
- `logo.svg` and `logo-light.svg`: transparent native SVG paths traced from the supplied artwork; no embedded raster images.
- `mark.svg` and `mark-light.svg`: transparent vector versions of the insect and wormhole emblem.
- `black-hole-universe.png`: generated black-hole background for the entry screen and subtle workspace surfaces.
- `../favicon.svg` and `../../src/app/icon.svg`: the compact mark used for browser metadata.

Dark surfaces use the light wordmark; light surfaces use the dark wordmark.

The background was generated with the built-in imagegen tool. See `docs/cosmic-background.md` at the repository root for the asset prompt and usage notes.

The repository README uses transparent PNG exports in `docs/assets/logo-on-dark.png` and `docs/assets/logo-on-light.png` for image-preview compatibility. They are rendered from the corresponding SVG wordmarks at 1510 × 560 pixels, with alpha preserved.
